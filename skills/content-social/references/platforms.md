# Platforms

Last reviewed: 2026-11-21 — formats, limits, algorithms and API access change often; verify current official specs and API terms before producing or scheduling.

| Platform | Strong for | Native formats | Notes |
|---|---|---|---|
| Instagram | B2C, visual products, lifestyle | Reels (vertical video), carousels, Stories, single images | carousels for education, Reels for reach; publishing via Meta's official API for business/creator accounts |
| TikTok | reach, younger audiences, entertainment/education | vertical short video | trend-native, sound matters; check music licensing for business accounts |
| YouTube | search, long-form trust, tutorials | long video, Shorts | titles/thumbnails decide clicks; chapters and captions |
| LinkedIn | B2B, recruiting, founder voice | text posts, documents (PDF carousels), video | personal profiles often outperform company pages |
| X | news, tech, real-time conversation | short text, threads, video | API access tiers and costs change — check |
| Facebook | local businesses, groups, older audiences | posts, groups, events, Reels | groups and events for community |
| Pinterest | evergreen discovery, products, DIY | vertical pins | long content lifespan, SEO-like |
| Threads / Bluesky / Mastodon | conversation, communities | short text | check API availability for scheduling |

## Scheduling tools
Official native schedulers (Meta Business Suite, YouTube Studio, LinkedIn native scheduling) are free. Third-party: Buffer, Later, Hootsuite (paid tiers);
open-source/self-hosted options exist (e.g. Postiz, Mixpost) — verify maintenance status and API support per platform.

## Asset basics
Vertical 9:16 for short video, 4:5 or 1:1 for feed images, captions burned in or uploaded (most viewers watch muted), alt text on images,
brand-safe zones for text overlay (avoid UI overlap at top/bottom).
