# Anti-generic checklist

## Default patterns that read as "AI-made / template"
| Pattern | Why it's generic | Replace with |
|---|---|---|
| Purple→blue / pink→orange gradients | the default of countless templates and generators | a palette taken from the brand's real world (material, place, product), 1 dominant + 1 accent |
| Inter / Poppins / Montserrat everywhere | safe defaults, no personality | a deliberate pairing: a characterful display face + a sober text face, chosen for the brand's adjectives |
| Hero + 3 feature cards + testimonial + CTA | identical to thousands of landing pages | structure from the content: lead with the product in use, a story sequence, a comparison, a configurator, a single strong image |
| Glassmorphism, heavy shadows, glow, floating blobs | decoration without meaning | flat surfaces, real photography, purposeful texture, one signature graphic device |
| Emoji or generic line icons as illustration | interchangeable | custom icon set with one drawing rule, or no icons |
| Abstract 3D shapes, stock "diverse team smiling" photos | signal nothing about this brand | real product, real people, real place; art direction notes |
| Rounded-everything (16–24 px radius on all) | default component libraries | a radius scale with intent (sharp for precision brands, soft for warmth) |
| Centered everything, symmetric grids | safe, static | asymmetric layouts, strong left alignment, deliberate white space |
| Monogram-in-a-circle / lightbulb / globe / swoosh logos | category clichés | a mark derived from the name's meaning, the founder's story or the craft |
| Copy: "Unlock", "Elevate", "Seamless" | AI marketing filler | concrete benefit in plain words (see agent-behavior banned phrases) |

## Questions that produce originality
1. What would this brand look like if it were a physical object, a place, a material?
2. What does every competitor do — and what's the opposite that still serves users?
3. What's the one signature element someone would recognise without the logo?
4. Which constraint can we embrace (one colour, one typeface, hand-drawn only, grid of 3)?

## Pass criteria
- Can't swap the logo for a competitor's without the design looking wrong.
- Every colour, font and layout choice has a one-sentence reason tied to the brief.
- No more than one "trendy" effect, and only if it supports the concept.
