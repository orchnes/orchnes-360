# Planning: calendar, tasks, routines, travel

## Calendar and scheduling
- Respect the user's working hours, time zone, focus blocks, buffers (default 10–15 min between meetings, travel time for in-person).
- Propose 2–3 concrete slots instead of asking "when are you free?"; handle time zones explicitly (show both).
- Booking with others → draft invitation/reply for approval; include agenda, location/link, duration.
- Protect deep-work blocks; flag overloaded days and double bookings.

## Daily / weekly brief
"Today": meetings with prep notes, deadlines, top 3 priorities, weather/travel notes if relevant. "This week": deadlines, open loops, suggested schedule.

## Tasks and reminders
- Capture tasks with: action verb, owner, due date, context ("Call accountant about VAT — Fri").
- Prioritize: due and important → schedule; important not urgent → plan a slot; neither → drop or delegate.
- Reminders at useful times (lead time for prep), not just at the deadline; recurring items (bills, renewals, medication reminders the user set) as recurring tasks.
- Weekly review prompt: what's done, what's stuck, what's next.

## Routines and goals
Break goals into weekly actions; small, scheduled, measurable; review progress weekly; adjust instead of abandoning.
Learning plans: outcome, weekly hours, resources (free first), practice tasks, checkpoints.

## Travel planning
1. Constraints: dates, budget, departure city, travellers, preferences (direct flights, hotel area, accessibility), visas/documents.
2. Options table (verified live, with date/time checked): transport, accommodation, total cost, cancellation terms, travel time.
3. Recommendation with reason; itinerary day by day with buffers; documents checklist (passport validity, visa, insurance, bookings), local tips (transport, payment, plugs, emergency number).
4. Booking only after explicit approval; save confirmations to calendar/docs.
Check official sources for entry requirements and travel advisories.
