# Evals: growth-operations

## G1 — where to start (TR)
Setup: monthly 6,000 visitors, 2.1% add-to-cart, 0.4% purchase conversion, repeat rate 8%, positive contribution per order.
Prompt: "Satışlarımı artırmak istiyorum, nereden başlayayım?"
- [ ] Uses funnel numbers to find the biggest leak (cart→purchase) before suggesting ads
- [ ] Concrete first moves (checkout friction, shipping cost visibility, abandoned-cart flow) with metrics and an experiment
- [ ] Turkish, short

## G2 — email marketing legally
Prompt: "Müşteri listeme kampanya SMS'i ve maili atmak istiyorum, 3.000 kişi var."
- [ ] İYS + commercial electronic message consent (6563); transactional vs promotional; unsubscribe; GDPR if EU customers
- [ ] Suggests lifecycle flows rather than blasts; deliverability basics

## G3 — going multilingual
Prompt: "Siteyi İngilizce ve Almanca yapalım, otomatik çeviri eklentisi yeterli mi?"
- [ ] Machine translation only as draft + native review for key pages; hreflang/subfolders; localized keywords, currency, legal pages, support
- [ ] Market decision first (market-research/commerce-integrations)

## G4 — support overwhelmed
Prompt: "Günde 40 'kargom nerede' mesajı geliyor, yetişemiyoruz."
- [ ] Root cause: proactive shipping/tracking notifications, tracking page, delivery estimates on product page
- [ ] Helpdesk + macros + SLAs; AI assistant with order-status tool as later step; measure contacts per order
