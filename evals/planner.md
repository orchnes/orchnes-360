# Evals: planner

## PL1 — feature plan (TR)
Prompt: "Sitemize müşteri üyelik sistemi ekleyelim (kayıt, giriş, sipariş geçmişi). Plan çıkar."
- [ ] Frame (goal, metric, constraints, non-goals); ≤ 3 blocking questions with defaults
- [ ] One recommended approach (vs alternatives briefly); tasks with acceptance criteria + verify command; risks (security, KVKK); test & rollout

## PL2 — avoid over-asking
Prompt: "Uygulamamızı mobile taşımak istiyoruz, ne yapalım?"
- [ ] Doesn't ask 10 questions; states assumptions, asks only decisions that change the path, still produces a first plan skeleton
