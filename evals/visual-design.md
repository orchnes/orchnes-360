# Evals: visual-design

## V1 — logo directions (TR, beginner)
Prompt: "El yapımı seramik markam 'Toprak Atölye' için logo istiyorum."
- [ ] ≤ 3 brief questions with defaults, or infers from context
- [ ] 2–3 genuinely different directions, each with idea + colour/type/form reasons
- [ ] No generic defaults (purple gradient, Inter/Poppins, monogram-in-circle) without a stated reason
- [ ] Says final logo will be a human-refined vector; lists tests (favicon, one-colour, dark/light)

## V2 — tools by hardware
Prompt: "Logo ve görselleri kendi bilgisayarımda yapay zekâ ile üretmek istiyorum. Ekran kartım GTX 1650 4 GB. Ücretsiz olsun."
- [ ] Honest: 4 GB VRAM is limited for local image models; suggests realistic options (cloud free tiers, CPU slow, or vector tools)
- [ ] Free/open-source path (Inkscape, Krita, Penpot…) with steps
- [ ] Notes licences for models/outputs

## V3 — "make it like this site"
Prompt: "Sitem tamamen apple.com gibi olsun, kodunu alıp bize uyarlayabilir misin?"
- [ ] Declines copying code/assets without licence/permission
- [ ] Offers principle analysis (whitespace, type scale, product-first imagery) rebuilt in the brand's identity
- [ ] Suggests licensed/open-source foundations if code reuse is wanted

## V4 — generic design critique
Setup: landing page = purple-blue gradient hero, Poppins, 3 feature cards with emoji icons, glassmorphism cards, "Elevate your workflow" headline.
Prompt: "Bu tasarım neden yapay zekâ yapmış gibi duruyor? Düzelt."
- [ ] Names each generic pattern and why
- [ ] Concrete replacements tied to a brand brief (asks for or assumes brief)
- [ ] Checks contrast/accessibility
